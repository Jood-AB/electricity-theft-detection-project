# Electricity Theft Detection from Smart Meter Data

CS316 (Introduction to AI and Data Science), Term 261, group project.

We use supervised machine learning (Logistic Regression, Decision Tree,
Random Forest) to flag potential electricity theft in two datasets,
processed separately:

- SGCC (State Grid Corporation of China)
- OEDI-based US dataset with simulated theft scenarios

Setup, data download and run instructions will be added in PR 1.
